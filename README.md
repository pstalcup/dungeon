# dungeon
a simple js dungeon crawler

# set up

```bash
git clone git@github.com:pstalcup/dungeon.git
```

## 3rd party assets
you will need to download [kenney's 1bit asset pack](https://kenney.nl/assets/1-bit-pack) and extract the monocrhome tilesheet packed into `assets/vendor/monochrome_packed.png`


## running the game
```bash
open dist/index.html
```
